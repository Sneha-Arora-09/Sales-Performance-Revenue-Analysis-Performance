# 📊 Sales Performance Dashboard – Power BI

## 📌 Project Overview

An interactive Power BI dashboard designed to analyze sales performance, revenue, profit, customers, and product trends.

## 🎯 Objectives

* Analyze total sales and profit
* Identify top-performing products
* Track sales trends over time
* Analyze customer performance
* Compare regional performance
* Provide actionable business insights

## 🛠️ Tools Used

* Power BI
* DAX
* Power Query
* Excel / CSV
* Data Visualization

## 📈 Key KPIs

* Total Sales
* Total Profit
* Total Orders
* Profit Margin
* Number of Customers
